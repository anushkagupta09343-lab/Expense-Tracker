# 💰 Expense Tracker

A simple and interactive expense tracking dashboard built using HTML, CSS and JavaScript.

## ✨ Features

* ➕ Add new expenses
* 🗑️ Delete expenses
* 💰 Automatically calculate total expenses
* 📋 View expense history
* 📊 Track spending
* 💾 Save expense data using LocalStorage
* 📱 Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* LocalStorage

## 📌 Project

This project helps users record and manage their daily expenses through a simple and interactive dashboard.
